The MP3 is unchanged. In-game playback normalizes its peak, applies a 0.3 gain,
and uses a 0.35 playback rate for a deeper pitch and longer thump (about 3.7 seconds).
Playback skips the quiet lead-in, starting 1 ms before the first sample reaching
2% of the peak amplitude so the audible attack coincides with the jump.
The clip is slowed, not duplicated or looped. Used as a one-shot effect for first
jumps and both non-directional and directional second jumps.
